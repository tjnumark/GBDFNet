# GBDFNet
A Dual Branch Fusion Network for Simultaneous Tea Leaf Disease Diagnosis and Age-Based Quality Grade Evaluation

## Our paper titled *A Dual Branch Fusion Network for Simultaneous Tea Leaf Disease Diagnosis and Age-Based Quality Grade Evaluation* has been accepted by Plants ([https://doi.org/10.3390/plants15152391](https://www.mdpi.com/2223-7747/15/15/2391)). 

## Environment Setup
The code is implemented in PyTorch and for illustration only. Full datasets can be downloaded from: The tea leaf disease recognition dataset analyzed in this study is available from https://data.mendeley.com/datasets/744vznw5k2/3 (accessed on 11 February 2026), and the tea leaf grading dataset is available from https://data.mendeley.com/datasets/7t964jmmy3/1 (accessed on 11 February 2026).
